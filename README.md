# Wajose Main Shop – WordPress demo

A demo of the Wajose Main Shop site (executive footwear, sneakers, menswear and wholesale packs, Nairobi) that runs entirely in the browser with WordPress Playground: a block theme on Twenty Twenty-Five with the catalogue as WooCommerce products (sizes, colours, retail and wholesale prices), a quick-buy dialog, a cart with automatic wholesale pricing and WhatsApp checkout.

- Shop: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/wajose-demo/main/blueprint.json
- Admin (products, prices, sizes, photos): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/wajose-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so changes are not kept.
